# Registro de cambios

## 17 de septiembre de 2026 — Mejoras visuales de Institucional

- Se reorganizó la grilla de **Instalaciones** para que cada tarjeta conserve un ancho mínimo legible y tenga más separación entre elementos.
- Se mejoraron las tarjetas de instalaciones: mayor espacio interno, títulos más claros, texto alineado a la izquierda y un separador visual entre el botón y la descripción.
- Se actualizaron las tarjetas de **Materias de Especialidad** con márgenes, bordes y sombras más suaves.
- Se diseñaron las tablas que se muestran al pulsar “Ver más”: encabezados destacados, filas espaciadas, mejor contraste y desplazamiento horizontal seguro en pantallas angostas.
- Se cerró correctamente la sección HTML de instalaciones antes de comenzar la sección de materias.
- Se reemplazó la flecha textual del menú **Institucional** por un indicador dibujado con CSS, alineado con el texto y animado al abrir el submenú.
- Se rediseñó la barra de navegación completa: marca, enlaces, botón de contacto, título de página y submenú ahora comparten una jerarquía visual consistente y una versión adaptable para pantallas pequeñas.
- Se eliminó el espacio entre **Institucional** y su submenú para que se pueda pasar el cursor y seleccionar sus opciones sin que se cierre.

Archivos modificados: `templates/institucional.html` y `static/style.css`.
